How approval works

Four steps, enforced by the server — not just hidden buttons.

Ask for Partner Approval

  • Sends the approval e-mail template to every approver
  • Schedules a To-Do activity for each approver
  • Posts a note in the chatter listing who was asked
  • Clear error if no approver is configured yet

Approve Partner

  • Only configured approvers can approve
  • Data-quality gate: Country is required for customers / vendors
  • Assigns missing Customer / Vendor codes from sequences
  • Records Approved by, closes pending To-Dos and notifies creator

Locked once approved

  • Name, type, address, e-mail, phone, tax ID, tags, codes, purchase terms and more become read-only
  • Enforced in write() — RPC, import and scripts are refused too
  • Core flows (payments, bank statements, child contacts) keep working

Set to Draft

  • Available to approvers
  • … and to users with the Allow Partner Set to Draft access right
  • Clears the approval so the partner can be edited and re-approved

Frequently asked questions

Click a question to expand the answer. Still unsure? Email us before you buy.

Which Odoo editions are supported?

Odoo 19 Community, Enterprise and Odoo.sh. Odoo Online (SaaS) does not allow third-party apps.

Which apps does it depend on?

Contacts, Discuss (mail) and Invoicing / Accounting. No other third-party modules.

Can users bypass the lock through import or the API?

No. The lock is checked in the model's write(), so changes to protected fields of an approved partner are refused from the UI, import, XML-RPC/JSON-RPC and server actions. Developers can extend the list via _approved_locked_fields().

Will it break payments or bank statement imports?

No. Child contacts and bank accounts are deliberately not server-locked, because core Odoo writes them from payment registration and statement import.

Can I type my own customer / vendor code?

Yes. Codes are editable while the partner is in Draft. The sequence is used only if the code is still empty at approval. Codes must be unique.

Are approvers set per company?

Yes. Approvers are stored on the company, so each company in a multi-company database can have its own approvers.

What happens to existing contacts after install?

They start in Draft and remain fully usable. Approve them when convenient — nothing is locked until a partner is approved.
